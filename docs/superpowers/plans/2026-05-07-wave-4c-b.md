## Scope (narrow)

**В скоупе:**
- (1) Меню профилей с **описанием** (manifest.description) и **аудиторией** (manifest.audience, если есть) — вместо плоского `- name`.
- (2) После выбора профиля — **summary block**: что будет применено (# operations, # overrides, # subagents core/optional/disabled).
- (3) **Confirm gate** перед применением: "Apply this profile? (Y/n)" — если non-interactive (no TTY) или `INIT_FORCE=1`, skip prompt и proceed.
- (4) Обновить документацию в CLAUDE.md и extending.md.

**Не в скоупе (отложено в W4c-C):**
- Override toggles (per-override y/n prompts) — требует расширения `init_prompts` mechanic
- Profile recommendation wizard ("what are you building?")
- Migration tooling (`migrate-profile.sh`, `upgrade-template.sh`)
- Plugin-rename feature
