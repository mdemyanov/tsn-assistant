## Ключевые зависимости

- **Сахабетдинов** — критичен для пред-проектной валидации: pgvector на `llm2`, схема под векторы, сетевой доступ к Yandex Cloud. Подтверждение этих пунктов — gate выхода из PoC-инициации.
- **Сазонова** — gate-keeper деплоя через `smps`. Подключается с первой итерации `/dev`, когда есть JAR для smoke.
- **Демьянов** — единственный носитель доменной экспертизы и приёмщик PoC (нет внешнего BA/PO в PoC-фазе).

## Out of scope для PoC

- Бутяйкин (владелец продукта Service Desk) — подключается, если PoC переходит в продуктовую интеграцию с ITSM 365 Support.
- Команда направления прикладных продуктов (Павлов / Озорнин / Пермяков / Кирпиченков) — подключается на фазе Pilot, если решение масштабируется в SaaS-формат.
