**Goal:** Перевести 4 stub профиля (`product`, `methodology`, `course`, `custom`) в `status: stable` — наполнить полным контуром (content-scaffold/ + doc-root.yaml + operations + agent_overrides + example каталог + test-template assertions).

**Architecture:** Каждый профиль повторяет паттерн `kb-team` / `kb-product`:
- `docs/overlays/profiles/<name>/manifest.yaml` — `status: stable`, `operations: [add scaffold, replace doc-root]`, `agent_overrides: { <role>: source: agent-overrides/<role>.md }`
- `docs/overlays/profiles/<name>/content-scaffold/` — типизированная структура для домена
- `docs/overlays/profiles/<name>/doc-root.yaml` — properties + iconUrl
- `docs/overlays/profiles/<name>/agent-overrides/<role>.md` — минимум 1 override (демонстрация механики)
- `examples/<name>-example/` — regenerated example каталог
- `scripts/test-template.sh` — T-W4c-<NAME> ассерты

**Tech Stack:** Bash (apply-overlay), Python 3 (helpers), YAML manifests, Gramax markdown.
